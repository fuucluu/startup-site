# QuantaDev Labs website

Static GitHub Pages site for [www.quantadev.xyz](https://www.quantadev.xyz/).

- `index.html` — product overview and conversion page
- `craft-fair-calculator.html` — free profit and break-even calculator
- `fair-margin.html` — Fair Margin product page
- `sheetclean-pro.html` — SheetClean Pro product page

The calculator runs entirely in the browser and does not transmit or store user inputs.
